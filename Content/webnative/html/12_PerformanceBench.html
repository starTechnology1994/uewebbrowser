What is being tested?

English

This benchmark evaluates CEF/WebView rendering stability under stress:

  • FPS & Frame Time — Measures render loop smoothness. Drops indicate GPU/CPU contention between CEF compositing and UE rendering.
  • JS Heap Memory — Tracks performance.memory.usedJSHeapSize. Rising without recovery suggests a memory leak in JS runtime or DOM retention.
  • DOM Node Count — Counts all active DOM elements. Massive growth stresses the layout engine and CEF's internal render tree.
  • Stress Payload — Injects Intensity × 3000 JSON objects + Intensity × 500 DOM elements per tick, simulating a heavy real-time dashboard workload.
  • Recovery Check — After the test stops, verifies memory drops back. Failure to recover indicates a DOM/JS leak.
  • Timeline Charts — Visualize FPS dips, memory spikes, and DOM surges over time so you can pinpoint bottlenecks.

中文

此基准测试评估 CEF/WebView 在压力负载下的渲染稳定性：

  • FPS 与帧时间 — 衡量渲染循环流畅度。下降意味着 CEF 合成与 UE 渲染之间的 GPU/CPU 竞争。
  • JS 堆内存 — 追踪 performance.memory.usedJSHeapSize。只升不降说明 JS 运行时或 DOM 存在内存泄漏。
  • DOM 节点数 — 统计所有活跃 DOM 元素。大量增长会给布局引擎和 CEF 渲染树带来压力。
  • 压力负载 — 每周期注入 强度 × 3000 个 JSON 对象 + 强度 × 500 个 DOM 元素，模拟重载实时仪表盘工作负载。
  • 恢复检测 — 测试停止后验证内存是否回落。未回落说明存在 DOM/JS 泄漏。
  • 时间线图表 — 可视化 FPS 下降、内存峰值和 DOM 激增随时间的变化，便于定位瓶颈。
